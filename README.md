# 微信账单拼收款

导入微信账单 → **多选**具体消费 → 自动算总金额/人均，并生成一条写清**日期、时间、消费来源、具体金额**的群收款备注，复制后去微信粘贴即可。纯本地网页工具，**不联网、不上传、零依赖**。

## 为什么做成网页（PWA）而不是 App？

| 考量 | 结论 |
| --- | --- |
| 安全 | 账单含交易单号、商户单号等敏感信息。本工具是纯静态页面：没有后端、没有数据库、不发任何网络请求，解析和数据保存（IndexedDB）全部发生在你自己的浏览器里，代码全部本地可审计。任何“帮你传到云端记账”的方案都做不到这一点。 |
| 实用性（鸿蒙） | 纯血鸿蒙（HarmonyOS NEXT）不能安装安卓 APK，自研鸿蒙应用又需要华为签名与上架审核——个人自用 App 很难走通。网页在华为浏览器/微信内置浏览器/电脑浏览器都能直接用，还可“添加到主屏幕”当 App 用。 |
| 维护 | 无构建、无依赖，就是几个 HTML/JS 文件，改起来直观。 |

## 功能

- **导入微信发来的 zip（推荐）**：邮箱收到的账单压缩包**直接导入**，内置解压（标准 zip 密码加密），无需手动解压；解压密码可勾选"记住"，下次自动填充。
- **导入 Excel(.xlsx)**：微信电脑版「账单与交易 → 导出账单」直接导出的 Excel 文件**免密码直接导入**（自动转换 Excel 串行日期、共享字符串，兼容稀疏单元格）。
- **解析微信账单 CSV**：自动识别编码（微信导出为 GBK，兼容 UTF-8/UTF-16），自动跳过账单摘要头，按"交易单号"去重（重复导出/区间重叠都不会重复记账），可解析引号内逗号/引号转义。
- **多选消费**：按关键字、日期范围、收支类型筛选，支持全选筛选结果/反选；底部实时显示已选笔数与合计。
- **生成群收款**：
  - 总金额与人均（分单位精确累加，无浮点误差）；
  - 备注模板可自定义，占位符：`{日期} {时间段} {笔数} {合计} {人均} {人数} {来源} {明细} {明细单行}`；默认“详细”模板每笔一行，含日期·时间·来源·金额；
  - 一键复制：收款备注 / 群明细（多行版）/ 总金额 / 金额＋备注。
- **数据管理**：本机持久化（IndexedDB）、导出 JSON 备份、恢复备份、一键清空。
- **PWA**：在 https 或 localhost 下可安装到主屏幕、离线使用。

## 快速开始

### 方式一：电脑上直接用
双击 `index.html` 即可（核心功能完整；仅持久化/PWA 在个别浏览器受限，页面会提示）。

### 方式二：本地起服务（推荐，电脑使用最方便）
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File serve.ps1
```
然后电脑浏览器打开 <http://localhost:8432/>。

`serve.ps1` **只绑定 localhost**（已实测：伪造局域网 Host 头会被 http.sys 以 400 拒绝），局域网内其他设备访问不到，静态代码不会暴露给同网段。

想在手机上用：走下方 GitHub Pages（数据同样只存手机浏览器本地）。若确需局域网直连手机，把 serve.ps1 里的 `http://localhost:8432/` 改为 `http://+:8432/` 并放行防火墙——但这会让同网段设备都能拿到页面代码（账单数据仍只在各设备浏览器内，不上传），不建议在公共 Wi-Fi 下这样做。

### 方式三：部署到 GitHub Pages（手机长期使用最省心）
1. 把本目录推送到 GitHub 仓库；
2. 仓库 Settings → Pages → Branch 选 `main` / 根目录；
3. 手机浏览器打开 `https://<用户名>.github.io/<仓库名>/`，菜单里选“添加到主屏幕”。

代码是静态文件，托管在 GitHub Pages 也不会上传你的账单——数据仍只存在浏览器本地。

## 微信账单导出步骤（唯一的手动部分）

**方式 A：微信电脑版直接导出（推荐，不经过邮箱）**
微信电脑版 → 左下角「···」→ 设置 → 通用设置 → **账单与交易 → 导出账单** → 选时间范围，**格式选 CSV** → 文件直接发到 PC 微信/保存到本地 → 把 zip（或 CSV）拖进本工具，输一次解压密码（导出时微信弹窗显示，可勾选记住）。

**方式 B：手机微信邮箱导出**
微信 → 我 → 服务 → 钱包 → 账单 → 右上角「常见问题/客服中心」→ 下载账单 → 选「用于个人对账」→ 选时间段 → 填邮箱；zip 发到邮箱，解压密码在微信「下载记录」页或「微信支付」服务号消息里查看。收到 zip 后直接拖进本工具即可（手机上：微信里点开 zip → 保存到手机 → 浏览器的文件选择器里选它）。

之后的一切已自动化：自动解压、解析、去重入库。微信没有开放账单接口，App 内这几步导出点击是任何第三方工具都无法替代的。

> 小技巧 1：因为按"交易单号"去重，导出时间段有重叠也没关系，重复导入不会产生重复账单。
> 小技巧 2：电脑浏览器和手机浏览器的数据各自独立；要把电脑的数据带到手机，用「导出备份 (.json)」→ 微信/邮箱发给手机 → 手机端「导入备份」。

## 生成群收款的完整流程

1. 导入账单，用筛选/搜索定位要一起收款的几笔消费，**勾选**；
2. 点底部「生成群收款」，填参与人数，选/编辑备注模板；
3. 点「复制收款备注」（明细长就再复制一条「群明细」发群里）；
4. 打开微信群聊 → ＋ → 群收款 → 「按人均摊」填入总金额与人数 → 把备注粘贴进「收款说明」→ 发送。

> **为什么最后一步是手动的？** 微信没有向第三方开放“发起群收款”的接口或深链，任何第三方都无法替你在微信里发起收款。本工具把“金额算准、备注写全”这两件最繁琐的事自动化，最后一步只需约 10 秒手动操作。

## 隐私与安全

- 无后端、无 CDN、无字体/统计等任何外部请求（可直接断网使用）；
- 账单数据保存在浏览器 IndexedDB，仅本机可读；换设备请先「导出备份」；
- 勾选「记住密码」时，zip 解压密码仅保存在本机浏览器，用于下次自动填充；不勾选则每次手输；
- 服务端（如 GitHub Pages）只托管代码，不接触数据；
- 敏感操作（清空）有二次确认。

## 已知限制

- 不能真正"替你发起"微信群收款（微信未开放接口），只生成总金额与备注文案；
- 微信 App 内的账单导出点击（选时间段/填邮箱）无法自动化——微信不开放该能力，任何声称能直连微信账单的工具都值得警惕；
- zip 解压依赖浏览器原生 DecompressionStream（近几年的主流浏览器都支持）；若微信未来改用 AES 加密压缩包，工具会提示并回退为"手动解压后导入 CSV"；
- 支持微信支付账单 zip / CSV / XLSX 三种形态；暂不支持支付宝账单（解析器已模块化，可扩展）。
- 群收款说明若超出微信字数限制，请改用「复制群明细」把明细发到群里，备注留汇总行。

## 项目结构

```
index.html            页面结构
styles.css            样式（移动优先、深色模式自适应）
parser.js             核心：编码探测 / CSV 解析 / 收款文案生成（纯函数）
unzip.js              零依赖 ZIP 读取（ZipCrypto 解密 + 原生 deflate 解压）
xlsx.js               零依赖 XLSX 读取（XML 提取、共享字符串、Excel 串行日期转换）
app.js                页面逻辑：导入（zip/xlsx/csv/备份）、筛选、多选、IndexedDB、弹层
manifest.webmanifest  PWA 清单
sw.js                 Service Worker（离线缓存）
icon.svg              图标
serve.ps1             零依赖本地静态服务器（PowerShell）
make-sample.ps1       生成 GBK 编码示例账单
sample/               示例账单（wechat-bill-sample-gbk.csv，均为假数据）
test/test.html        浏览器内测试页（解析器 + zip 解压全链路测试）
test/zip-utils.js     测试专用：按规范反向构建加密 zip（与 unzip.js 交叉验证）
```

## 开发与测试

打开 `http://localhost:8432/test/test.html` 查看解析器测试（编码、CSV 转义、去重、求和、文案生成、端到端 GBK 文件解析）。

注意：`*.ps1` 一律只用 ASCII 字符——PowerShell 5.1 会把无 BOM 的脚本按 ANSI/GBK 解析，中文字面量会变乱码。
